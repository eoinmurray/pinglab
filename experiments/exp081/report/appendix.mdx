## Appendix A — Simulation and theory details

### A1 — Simulate one pixel’s voltage feature

We set the normalized pixel intensity to its maximum, $x = 1$, and varied only its input rate $r_{\text{input}}$, from {pInputRateGridHzFirst} to {pInputRateGridHzLast} spikes/s. At each simulation step, the pixel either generated an event or did not. The event probability was

<span id="exp081-equation-a1" />

$$
p_{\text{event}} = \frac{r_{\text{input}} \Delta t_{\text{sim}}}{1000} .
\tag{A1}
$$

Here $r_{\text{input}}$ is the input rate in spikes/s and $\Delta t_{\text{sim}} =$ {pDtMs} ms is the length of one simulation step. Over a presentation lasting $T_{\text{present}} =$ {pPresentationMs} ms, the expected event count is $r_{\text{input}} \frac{T_{\text{present}}}{1000}$. We therefore controlled the rate; the number of events in an individual presentation remained random.

Each event increased AMPA conductance, which then decayed over time:

<span id="exp081-equation-a2" />

$$
g [ k ] = \beta_{\text{AMPA}} g [ k - 1 ] + w_{\text{event}} s [ k ] ,
\tag{A2}
$$

<span id="exp081-equation-a3" />

$$
\beta_{\text{AMPA}} = \exp(-\Delta t_{\text{sim}}/\tau_{\text{AMPA}}) ,
\tag{A3}
$$

<span id="exp081-equation-a4" />

$$
C_{m} \frac{d V_{m}}{d t} = g_{L} ( E_{L} - V_{m} ) + g ( t ) ( E_{e} - V_{m} ) .
\tag{A4}
$$

The indicator $s [ k ]$ equals one when step $k$ contains an event and zero otherwise. The AMPA conductance at that step is $g [ k ]$; each event adds $w_{\text{event}}$. Between events, conductance retains the fraction $\beta_{\text{AMPA}}$ from the previous step, as set by the AMPA decay time $\tau_{\text{AMPA}}$. Membrane voltage $V_m(t)$ then follows [Equation A4](#exp081-equation-a4), where $C_{m}$ is membrane capacitance, $g_{L}$ is leak conductance, $E_{L}$ is the resting leak potential and $E_{e}$ is the excitatory reversal potential.

We used $C_{m} = 1$ nF, $g_{L} = 0.05$ μS, $E_{L} = - 65$ mV, $E_{e} = 0$ mV, $\tau_{\text{AMPA}} = 2$ ms, and event strengths $w_{\text{event}} \in \{${probeConductances}$\}$ μS. Every presentation began with no AMPA conductance, $g ( 0 ) = 0$, and the membrane at rest, $V_{m ( 0 )} = E_{L}$. We defined its voltage feature as

<span id="exp081-equation-a5" />

$$
z_{\text{feature}} = \frac{1}{T_{\text{present}}} \int_{0}^{T_{\text{present}}} ( V_m(t) - E_{L} ) \, \mathrm{d} t .
\tag{A5}
$$

The feature $z_{\text{feature}}$ is the average voltage above rest during the presentation. In the discrete simulation, we approximated this integral by averaging the voltage after each update and subtracting $E_{L}$.

For the mean and SD estimates in Figure 1, we generated {pMomentDraws} new presentations at each of {pInputRateGridHzLen} input rates and each conductance. For the full response distributions in Figure 2, we generated {pDistributionDraws} new presentations at each selected rate. This direct simulation preserves the random event counts and timings, the start from rest, and their combined effect within the finite presentation\[[1](#ref-1)\].

### A2 — Replace random input with its steady average

The simpler theory begins by replacing the changing AMPA conductance with its long-run average. For an ongoing Poisson input at rate $r = r_{\text{input}}$, filtered-shot-noise theory\[[2](#ref-2)\] gives this mean as

<span id="exp081-equation-a6" />

$$
\bar{g}_{r} = r w_{\text{event}} \frac{\tau_{\text{AMPA}}}{1000} .
\tag{A6}
$$

Holding conductance at this mean gives the corresponding steady membrane voltage:

<span id="exp081-equation-a7" />

$$
\bar{v}_{r} = \frac{g_{L} E_{L} + \bar{g}_{r} E_{e}}{g_{L} + \bar{g}_{r}} .
\tag{A7}
$$

Because this voltage does not change during the presentation, the predicted mean feature is simply its rise above rest:

<span id="exp081-equation-a8" />

$$
\mu_{\text{linear}} ( z ) = \bar{v}_{r} - E_{L} .
\tag{A8}
$$

An overbar marks a steady average. Thus $\bar{g}_{r}$ is the mean conductance at input rate $r$, $\bar{v}_{r}$ is the voltage produced by that mean conductance, and $\mu_{\text{linear}} ( z )$ is the theory’s predicted mean voltage feature. [From events to steady conductance and voltage](#sec-stationary-conductance-and-voltage) derives Equations A6–A8 from the continuous conductance and membrane equations.

### A3 — Predict responses to slow and fast changes

Next, we asked how a small change in input rate would change voltage around the steady state. Treating these changes as small makes the equations linear and gives

<span id="exp081-equation-a9" />

$$
G_{r} ( \omega ) = \frac{w_{\text{event}}}{i \omega + \frac{1}{\tau_{\text{AMPA}}}} \cdot \frac{E_{e} - \bar{v}_{r}}{i \omega C_{m} + g_{L} + \bar{g}_{r}} .
\tag{A9}
$$

Here $\omega$ is angular frequency in rad/ms and $i$ is the imaginary unit. The transfer function $G_r(\omega)$ tells us how strongly voltage responds to an input change at each frequency. It describes small changes around the steady state, not the full start-from-rest simulation. [Synapse and membrane response](#sec-synapse-plus-membrane-linearization) derives [Equation A9](#exp081-equation-a9).

The experiment does not use instantaneous voltage: it averages voltage over the presentation. That averaging has its own frequency response,

<span id="exp081-equation-a10" />

$$
A_{T_{\text{present}}} ( \omega ) = \frac{1 - \exp ( - i \omega T_{\text{present}} )}{i \omega T_{\text{present}}} .
\tag{A10}
$$

which multiplies the synapse-and-membrane response to give the complete response from input rate to voltage feature:

<span id="exp081-equation-a11" />

$$
H_{r} ( \omega ) = A_{T_{\text{present}}} ( \omega ) G_{r} ( \omega ) .
\tag{A11}
$$

Here $A_{T_{\text{present}}} ( \omega )$ describes averaging over presentation duration $T_{\text{present}}$, and $H_r(\omega)$ describes the complete path from input-rate change to the averaged voltage feature. [Averaging over the presentation](#sec-finite-window-average) derives Equations A10 and A11.

To generate Figure 3, we evaluated Equations A9 and A11 from {pFrequencyPlotBoundsHzFirst} to {pFrequencyPlotBoundsHzLast} Hz at {frequencyResponseRates} spikes/s for the nominal {pNominalProbeUs} μS event strength. We converted frequency $f$ in Hz to angular frequency using $\omega = 2 \pi \frac{f}{1000}$. To compare response shapes, we expressed every magnitude relative to the steady response at the lowest input rate:

<span id="exp081-equation-a12" />

$$
M_{X} ( f ) = 20 \log_{10} ( \frac{\vert X_{r} ( 2 \pi \frac{f}{1000} ) \vert}{\vert X_{r_{\text{low}}} ( 0 ) \vert} ) .
\tag{A12}
$$

Here $M_{X ( f )}$ is response magnitude in decibels (dB). We used $X_{r} = G_{r}$ for Figure 3A and $X_{r} = H_{r}$ for Figure 3B. The variable $f$ is the frequency of the input change in Hz, and $r_{\text{low}}$ is the lowest steady input rate used as the reference.

### A4 — Predict variation in the voltage feature

An ideal Poisson event train has equal fluctuation power at every frequency. After subtracting its mean, its power across positive and negative frequencies on the millisecond time base is

<span id="exp081-equation-a13" />

$$
S_{\text{in}} ( \omega ) = \frac{r_{\text{input}}}{1000} .
\tag{A13}
$$

The filter scales that input power by ${\vert H_r(\omega) \vert}^{2}$. The predicted power spectrum of the voltage feature and its total variance are therefore

<span id="exp081-equation-a14" />

$$
S_{z} ( \omega ) = {\vert H_{r} ( \omega ) \vert}^{2} S_{\text{in}} ( \omega ) ,
\tag{A14}
$$

<span id="exp081-equation-a15" />

$$
{\text{Var}}_{\text{linear}} ( z ) = \frac{1}{2 \pi} \int_{- \infty}^{\infty} {\vert H_{r} ( \omega ) \vert}^{2} S_{\text{in}} ( \omega ) \, \mathrm{d} \omega .
\tag{A15}
$$

Here $S_{\text{in} ( \omega )}$ is the input power at each frequency, $S_{z ( \omega )}$ is the resulting feature power, and ${\text{Var}}_{\text{linear} ( z )}$ is the predicted variance of the voltage feature. [From Poisson events to feature variance](#sec-poisson-spectrum-and-feature-variance) derives Equations A13–A15.

We evaluated the integral in [Equation A15](#exp081-equation-a15) numerically on a logarithmically spaced frequency grid. We repeated the calculation with half as many points to check that the numerical result was stable.

### A5 — Why the simpler theory misses the variation

The simpler theory first averages conductance and then calculates the voltage response, written $z ( E [ g ] )$. The simulation instead calculates a response for every random conductance history and then averages those responses, written $E [ z ( g ) ]$. Because voltage saturates, these two operations are not interchangeable. Here the approximate relationship is

<span id="exp081-equation-a16" />

$$
E [ z ( g ) ] < z ( E [ g ] ) .
\tag{A16}
$$

The steady theory also treats input as if it acted throughout the whole presentation. In the simulation, an event arriving near the end contributes to the average in [Equation A5](#exp081-equation-a5) for only a short time.

More generally, the simulated feature distribution combines presentations with different event counts and, within each count, different event timings:

<span id="exp081-equation-a17" />

$$
p_{Z} ( z ) = \sum_{n = 0}^{\infty} P ( N = n ) p_{Z \vert N} ( z \vert n ) .
\tag{A17}
$$

Here $Z$ is the random voltage feature, $N$ is the event count, $P ( N = n )$ is the probability of observing $n$ events, and $p_{Z \vert N} ( z \vert n )$ is the distribution of feature values among presentations containing exactly $n$ events.

[Equation A15](#exp081-equation-a15) instead describes small fluctuations around one steady state. At low rates, a presentation with no events stays exactly at rest, a single large event produces a response that depends strongly on its arrival time, and multiple events interact through shunting and voltage saturation. This irregular mixture explains why the theoretical SD rose too sharply and peaked too early, especially for the strongest events.

## Appendix B — Derivation of the filtering approximation

<span id="sec-stationary-conductance-and-voltage" />

### B1 — From events to steady conductance and voltage

In the simulation, $s [ k ]$ records whether step $k$ contains an event. For the continuous-time calculation, we represent the same event sequence as $s ( t ) = \sum_{j} \delta ( t - t_{j} )$: a train of instantaneous impulses at event times $t_{j}$. AMPA conductance then follows

<span id="exp081-equation-b1" />

$$
\frac{d g}{d t} = - \frac{g}{\tau_{\text{AMPA}}} + w_{\text{event}} s ( t ) .
\tag{B1}
$$

Here $\delta ( t - t_{j} )$ is a Dirac impulse marking event $j$ at time $t_{j}$. Each impulse adds $w_{\text{event}}$ conductance, while existing conductance decays with time constant $\tau_{\text{AMPA}}$.

A steady input rate of $r$ spikes/s is $\frac{r}{1000}$ events per millisecond. To find the long-run mean conductance, we average [Equation B1](#exp081-equation-b1) and set its mean rate of change to zero:

<span id="exp081-equation-b2" />

$$
0 = - \frac{\bar{g}_{r}}{\tau_{\text{AMPA}}} + w_{\text{event}} \frac{r}{1000} ,
\tag{B2}
$$

Solving this equation gives [Equation A6](#exp081-equation-a6). At the corresponding steady membrane voltage, inward and outward current balance:

<span id="exp081-equation-b3" />

$$
0 = g_{L} ( E_{L} - \bar{v}_{r} ) + \bar{g}_{r} ( E_{e} - \bar{v}_{r} ) ,
\tag{B3}
$$

Rearranging the terms containing $\bar{v}_{r}$ gives [Equation A7](#exp081-equation-a7).

<span id="sec-synapse-plus-membrane-linearization" />

### B2 — Small changes through the synapse and membrane

We write each changing quantity as its steady value plus a small fluctuation:

<span id="exp081-equation-b4" />

$$
g = \bar{g}_{r} + \delta g , \quad v = \bar{v}_{r} + \delta v , \quad s = \frac{r}{1000} + \delta s .
\tag{B4}
$$

Substituting these expressions into [Equation B1](#exp081-equation-b1) makes the steady terms cancel, leaving an equation for the conductance fluctuation:

<span id="exp081-equation-b5" />

$$
\frac{d \delta g}{d t} = - \frac{\delta g}{\tau_{\text{AMPA}}} + w_{\text{event}} \delta s .
\tag{B5}
$$

In the frequency domain, differentiation with respect to time becomes multiplication by $i \omega$. The conductance response is therefore

<span id="exp081-equation-b6" />

$$
\delta g ( \omega ) = \frac{w_{\text{event}}}{i \omega + \frac{1}{\tau_{\text{AMPA}}}} \delta s ( \omega ) .
\tag{B6}
$$

We apply the same decomposition to the membrane equation, [Equation A4](#exp081-equation-a4). The steady terms cancel through [Equation B3](#exp081-equation-b3). Because the theory assumes small fluctuations, it drops their product $\delta g \delta v$, which is second order. This leaves

<span id="exp081-equation-b7" />

$$
C_{m} \frac{d \delta v}{d t} = - ( g_{L} + \bar{g}_{r} ) \delta v + ( E_{e} - \bar{v}_{r} ) \delta g .
\tag{B7}
$$

Transforming [Equation B7](#exp081-equation-b7) into the frequency domain and substituting [Equation B6](#exp081-equation-b6) gives [Equation A9](#exp081-equation-a9). Its denominator contains two filters: one from AMPA conductance and one from the membrane. The numerator contains the conductance added per event and the local voltage difference driving excitation.

<span id="sec-finite-window-average" />

### B3 — Averaging over the presentation

The fluctuation in the feature from [Equation A5](#exp081-equation-a5) is the average voltage fluctuation during the presentation:

<span id="exp081-equation-b8" />

$$
\delta z_{\text{feature}} = \frac{1}{T_{\text{present}}} \int_{0}^{T_{\text{present}}} \delta v ( t ) \, \mathrm{d} t .
\tag{B8}
$$

Averaging gives equal weight, $\frac{1}{T_{\text{present}}}$, to every time from zero to $T_{\text{present}}$ and zero weight outside that interval. The frequency response of this rectangular averaging window is

<span id="exp081-equation-b9" />

$$
A_{T_{\text{present}}} ( \omega ) = \frac{1}{T_{\text{present}}} \int_{0}^{T_{\text{present}}} \exp ( - i \omega t ) \, \mathrm{d} t = \frac{1 - \exp ( - i \omega T_{\text{present}} )}{i \omega T_{\text{present}}} ,
\tag{B9}
$$

which is [Equation A10](#exp081-equation-a10). Because the averaging happens after the membrane response, their two frequency responses multiply, giving [Equation A11](#exp081-equation-a11). The identity $1 - \exp ( - i x ) = 2 i \exp ( - i \frac{x}{2} ) \sin ( \frac{x}{2} )$ shows that the magnitude is

<span id="exp081-equation-b10" />

$$
\vert A_{T_{\text{present}}} ( \omega ) \vert = \vert \frac{\sin ( \omega \frac{T_{\text{present}}}{2} )}{\omega \frac{T_{\text{present}}}{2}} \vert ,
\tag{B10}
$$

With $T_{s} = \frac{T_{\text{present}}}{1000}$ s and $\omega = 2 \pi \frac{f}{1000}$,

<span id="exp081-equation-b11" />

$$
\vert A_{T_{\text{present}}} ( 2 \pi \frac{f}{1000} ) \vert = \vert \frac{\sin ( \pi f T_{s} )}{\pi f T_{s}} \vert .
\tag{B11}
$$

This response becomes zero at $f = \frac{n}{T_{s}}$, where $n$ is any nonzero integer. At those frequencies, the presentation contains a whole number of cycles, so positive and negative parts cancel in the average. The repeated dips and rebounds come from this sinc-shaped averaging response; the synapse and membrane make the overall response fall at higher frequencies.

<span id="sec-poisson-spectrum-and-feature-variance" />

### B4 — From Poisson events to feature variance

For ideal Poisson input at $\frac{r_{\text{input}}}{1000}$ events per millisecond, counts in separate time intervals are independent and the variance of each count equals its mean. After subtracting the mean event rate, the input autocovariance is

<span id="exp081-equation-b12" />

$$
C_{\delta s} ( \ell ) = ( \frac{r_{\text{input}}}{1000} ) \delta ( \ell ) .
\tag{B12}
$$

Here $C_{\delta s} ( \ell )$ measures how the centred input relates to itself after a time lag $\ell$. The Dirac delta $\delta ( \ell )$ means that this ideal input is correlated with itself only at zero lag.

The frequency transform of a Dirac delta is constant, which gives the flat input spectrum in [Equation A13](#exp081-equation-a13). A linear filter multiplies that spectrum by the squared magnitude of its frequency response, giving [Equation A14](#exp081-equation-a14). Adding the feature power across all frequencies then gives its variance:

<span id="exp081-equation-b13" />

$$
\text{Var} ( z ) = R_{z} ( 0 ) = \frac{1}{2 \pi} \int_{- \infty}^{\infty} S_{z} ( \omega ) \, \mathrm{d} \omega ,
\tag{B13}
$$

Substituting [Equation A14](#exp081-equation-a14) gives [Equation A15](#exp081-equation-a15). This result is exact for the simplified model with steady input and small linear fluctuations. It is only an approximation to the simulated system, which is nonlinear, begins each presentation from rest and contains a finite random number of events.
