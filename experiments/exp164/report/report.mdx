## Introduction

Two sensory populations, A and B, send excitatory projections to a shared
receiver C. Each circuit has local excitatory and inhibitory populations.
The sensory inputs encode two 8×8 scikit-learn digits through fixed pixel
connections. A separate cue excites one sender. The receiver's image is its
measured spatial firing-rate map, using a predefined neuron-to-pixel mapping.
No readout is trained.

## Discussion

The fixed topographic circuit preserves digit-like spatial patterns and changes
which pattern dominates C when the cue changes. Parameters were selected during
exploration; these two views use one image pair and one input realization.
Changes in sender firing rate accompany changes in timing. The figures therefore
support selective spatial output and cue-dependent gamma coupling without
isolating timing as the cause. The imported source trajectories, native start
arrays and original provenance are retained unchanged.
