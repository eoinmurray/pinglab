## Introduction

Two sensory populations, A and B, send excitatory projections to a shared
receiver C. Each circuit has local excitatory and inhibitory populations.
The sensory inputs encode two 8×8 scikit-learn digits through fixed pixel
connections. A separate cue excites one sender. The receiver's image is its
measured spatial firing-rate map, using a predefined neuron-to-pixel mapping.
No readout is trained.

## Discussion

The standalone recipe constructs the network, selects the first digit-0 and
digit-1 samples from scikit-learn, and generates matched sensory and background
spike trains for the two cue conditions. It requires no historical run. These
new trials use one fixed image pair and input realization; they do not establish
general digit selection. Changes in sender firing rate accompany changes in
timing, so phase coupling alone does not isolate timing as the cause of spatial
output. The corrected standalone trial reproduces the original two cue
conditions exactly at the level of generated inputs, native parameter arrays
and full population spike trains. Generated inputs, spikes, native start arrays
and configuration are retained.
