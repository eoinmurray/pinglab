## Introduction

Two sensory populations, A and B, send excitatory projections to a shared
receiver C. Each circuit has local excitatory and inhibitory populations.
The sensory inputs encode two 8×8 scikit-learn digits through fixed pixel
connections. A separate cue excites one sender. The receiver's image is its
measured spatial firing-rate map, using a predefined neuron-to-pixel mapping.
No readout is trained.

## Discussion

The selected standalone recipe uses 320 E and 80 I cells per circuit, with five
E cells per image pixel. Each sender pixel has 128 independent sensory channels;
C background and each cue projection use independent fixed fan-in masks of 128.
Local E→I fan-in is 80. Fixed excitatory target gain CV is 0.03 in A/B E,
zero in C E and 0.2 in I cells. C E retains private stochastic input despite
having no fixed gain bias. Local E→I and I→I strengths are multiplied by 0.8
and 0.1. Each sender supplies nominal 0.6 µS incoming excitation to C E and
0.12 µS to C I. The source image contrast is 0.075 and C background is 20 Hz/channel.
These changes were selected jointly through exploration; their separate causal
contributions were not established.

The code constructs the network and selects the first digit-0 and digit-1 samples
from scikit-learn without loading historical runs. The paired inputs and native
start arrays are retained. This modified condition does not reproduce the older
homogeneous trial. Historical successful and failed conditions remain immutable.
This is one fixed image pair and input realization, not evidence of general digit
selection or biological realism. Sender firing rate changes with timing, so phase
coupling does not isolate gamma timing as the cause of spatial output. No decoder,
classifier or synaptic weight is trained.
