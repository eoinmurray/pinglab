# exp128 — Introduction to conductance-based synapses

Explore exponential synaptic conductance and its effect on a leaky
integrate-and-fire neuron, including combined excitatory and inhibitory inputs.

1. No experiment CLI or external run input is required; the illustrative model
   runs interactively in the browser.
2. Sources: `report/report.mdx`, `report/SynapseAnimation.astro` and `report/js/`.
