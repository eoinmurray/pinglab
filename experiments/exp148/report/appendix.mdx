export const parameterGroups = (() => {
  if (!evidence) return [{ label: 'Network', rows: [['Native snapshot evidence', 'Unavailable']] }];
  const cfg = evidence.configuration;
  const snapshot = evidence.snapshots.simulation;
  const graph = snapshot?.network;
  const population = name => graph?.populations?.find(row => row.id === name);
  const projection = name => graph?.projections?.find(row => row.id === name);
  const parameter = name => graph?.parameters?.find(row => row.id === `${name}.weight`);
  const show = value => {
    const scalar = value?.value ?? value;
    if (scalar === undefined || scalar === null) return 'Unavailable';
    return typeof scalar === 'number' ? String(Number(scalar.toPrecision(6))) : String(scalar);
  };
  const pair = key => ['E', 'I'].map(name => show(population(name)?.neuron?.[key])).join(' / ');
  const names = ['E_to_E', 'E_to_I', 'I_to_E', 'I_to_I', 'X_to_E', 'X_to_I'];
  const label = name => name.replace(/^X_to_/, 'Input→').replace('_to_', '→').replace('.weight', ' weight');
  const density = name => {
    const zero = snapshot?.execution?.initialization?.[`${name}.weight`]?.statistics?.zero_fraction;
    return zero === undefined ? 'Unavailable' : show(1 - zero);
  };
  return [
    { label: 'Network', rows: [
      ['E / I neurons', ['E', 'I'].map(name => show(population(name)?.size)).join(' / ')],
      ['Shared Input sources', show(graph?.inputs?.find(row => row.id === 'X')?.shape?.at(-1))],
      ...names.map(name => [`${label(name)} autapses allowed`, show(projection(name)?.allow_autapses)]),
    ] },
    { label: 'Neurons', rows: [
      ['Neuron model, E / I', pair('kind')],
      ['Capacitance, E / I (nF)', pair('capacitance_nf')],
      ['Leak conductance, E / I (µS)', pair('leak_us')],
      ['Derived time constants, E / I (ms)', pair('tau_mem')],
      ['Resting potential, E / I (mV)', pair('resting_mv')],
      ['Initial voltage, E / I (mV)', pair('initial_voltage_mv')],
      ['Reset potential, E / I (mV)', pair('reset_mv')],
      ['Spike threshold, E / I (mV)', pair('threshold_mv')],
      ['Excitatory reversal, E / I (mV)', pair('excitatory_reversal_mv')],
      ['Inhibitory reversal, E / I (mV)', pair('inhibitory_reversal_mv')],
      ['Refractory duration, E / I (ms)', pair('refractory')],
      ['Refractory scheduling', show(graph?.refractory_timing)],
    ] },
    { label: 'Synapses and weights', rows: names.flatMap(name => {
      const spec = parameter(name);
      const init = spec?.initializer;
      const stats = snapshot?.execution?.initialization?.[`${name}.weight`]?.statistics;
      return [
        [`${label(name)} synapse / decay / delay (ms)`, [projection(name)?.synapse?.kind, projection(name)?.synapse?.tau, projection(name)?.delay].map(show).join(' / ')],
        [`${label(name)} modulation`, projection(name)?.modulation?.kind ?? 'None'],
        [`${label(name)} initializer / scaling`, [init?.kind, spec?.initialization_scaling].map(show).join(' / ')],
        [`${label(name)} compensated initializer mean / SD (µS)`, [init?.mean, init?.std].map(show).join(' / ')],
        [`${label(name)} connected Gaussian parent mean / SD (µS)`, init && typeof init.initial_zero_fraction === 'number' ? [init.mean / (1 - init.initial_zero_fraction), init.std / (1 - init.initial_zero_fraction)].map(show).join(' / ') : 'Unavailable'],
        [`${label(name)} realised nonzero mean (µS)`, stats && stats.zero_fraction < 1 ? show(stats.mean / (1 - stats.zero_fraction)) : 'Unavailable'],
        [`${label(name)} initial zero fraction / realised nonzero fraction`, [show(init?.initial_zero_fraction), density(name)].join(' / ')],
        [`${label(name)} realised mean / SD including zeros (µS)`, [stats?.mean, stats?.std].map(show).join(' / ')],
      ];
    }) },
    { label: 'Input and simulation', rows: [
      ['External input', 'One Poisson raster shared by Input→E and Input→I'],

      ['Spikes recorded', 'All E and I neurons; raw recording includes burn-in'],
      ['Excluded burn-in (ms)', show(cfg.burn_in_ms)],
      ['Measurement window (ms)', show(cfg.duration_ms - cfg.burn_in_ms)],
      ['Input-generation block length (steps)', show(cfg.recording_block_steps)],
      ['Training', snapshot?.execution?.parameter_membership?.trainable?.length === 0 ? 'None; gains follow prescribed native modulation' : 'Unavailable'],
    ] },
    { label: 'Control protocol', rows: [
      ['Scheduled parameter', label(cfg.control?.parameter ?? 'Unavailable')],

## C. Hold-window analysis

Pulse timing is measured independently in consecutive 100 ms intervals using
0.5 ms population-count bins, a minimum peak separation of 6 ms and prominence
of 12% of the largest count in each interval. This local threshold retains
small early volleys that the full-hold threshold can miss. Intervals crossing
100 ms boundaries are omitted. The last interval is shorter when the hold
duration is not a multiple of 100 ms. These descriptive measurements do not establish
a PING mechanism. Native recordings also retain population mean voltage and mean
conductance for each pathway. This runset contains no pathway-ablation controls.

## D. Four-state mean-field extension

The model in the main text is an adapted extension of [exp117](/exp117), using
its population-rate and conductance variables. It is a population closure, not
an exact reduction of the spiking network. No exp117 numerical results are used
as scientific inputs. All six couplings are calculated from exp148's explicitly
referenced native parameter snapshot, not from initializer means.

The stationary gain uses exp148's capacitance, leak, resting/reset/threshold
voltages and refractory periods. The 4 mV voltage-noise scale and 20/5 ms
E/I rate-relaxation times are unchanged exp117 assumptions. The gain's Siegert
integral and derivative are given in [exp117, Equations A10 and A15](/exp117#loc-11),
following [Kreutz-Delgado (2015)](https://doi.org/10.48550/arXiv.1501.04032).
The original ms-based rate is multiplied by 1,000 to obtain Hz.

E→E excitation and E→I excitation share one presynaptic population and decay
constant, as do I→I and I→E inhibition. Their homogeneous mean conductances are
therefore proportional when initialized consistently, as at the equilibrium
used here. This permits the two self-coupling conductances to be reconstructed
from the two cross-population conductance states. It does not assert exact
proportionality between conductances of individual neurons in the sparse
spiking circuit. Different decay constants or independent initial conductance
components would require additional states.

External input is replaced by its instantaneous stationary mean. The changing
external drive's 5 ms filtering lag and the shared pool's covariance are omitted.
Fixed resting-voltage driving forces omit shunting; weight heterogeneity and
explicit synaptic transmission delays are also omitted.

Equilibria are continued through 201 multipliers from one to zero using bounded
least squares, requiring a maximum rate residual below $10^{-7}$ Hz. This follows
one numerically found branch and does not establish global uniqueness. Gain
integrals use 48-point Gauss–Legendre quadrature. The analytical four-by-four
conductance-state Jacobian is checked against finite differences, with step sizes
scaled to each state variable's units. A direct change-of-coordinates check
preserves the flow and Jacobian of the earlier filtered-rate formulation.
Brent refinement locates a zero of the largest eigenvalue real part. At the
reported crossing, the critical pair has nonzero imaginary part, the remaining
pair stays stable, and the real part changes with the multiplier. These are
local Hopf conditions, not a determination of bifurcation criticality. Doubling
the quadrature resolution to 96 points preserves the crossing's eigenvalues
to numerical precision.

The matched protocol uses the recorded 50 ms burn-in and three 750 ms windows.
Its initial state is the full-drive equilibrium with a 0.001 Hz E-rate
perturbation. LSODA uses relative tolerance $10^{-8}$ and absolute rate tolerance
$10^{-10}$ Hz. Each conductance's absolute tolerance is the rate tolerance
multiplied by its equilibrium conductance-per-rate factor,
$\tau_sG_{E\to I}/1000$ or $\tau_sG_{I\to E}/1000$ in µS/Hz. This rescales the
previous error controls without changing the model. Maximum step and output
sampling interval are both 0.5 ms. Neither closure constants nor coupling
strengths are fitted to the observed transition.
