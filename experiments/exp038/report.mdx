abstract: "We asked what happens when reciprocal inhibition is added after a feedforward classifier has already been trained. We kept the learned input and readout weights fixed while progressively enabling bidirectional excitatory–inhibitory coupling during inference. Stronger coupling grouped activity into bursts and sharply suppressed excitatory firing, but also reduced classification accuracy. This demonstrates post-training rate suppression, not a benefit of gamma timing or evidence that retraining would recover the lost accuracy."

## Methods

We reused networks from the [exp022](/exp022) — [*Training Runs*](/exp022) and reanalysed recorded inference observations. No new training or simulation was performed for this account.

1. **Reuse trained classifiers.** MNIST handwritten digits \[[1](#ref-1)\] supplied 6,300 training and 700 validation images from the official training partition. Conductance-based leaky-integrate-and-fire networks had 784 Poisson input channels, 1,024 excitatory (E), 256 inhibitory (I), and 10 output neurons; pixels set rates up to 25 Hz. Input and readout weights trained for 50 epochs; class scores were mean pre-reset output voltages. We selected the minimum mean validation cross-entropy over three fixed encoding draws, breaking ties by accuracy and then earliest epoch, rather than using final-epoch weights.

2. **Enable the loop after training.** Three feedforward controls, seeds 42–44, had no activity penalty or recurrent coupling during training. Dimensionless strength <NativeMath markup={formulae[1]} /> took eleven values from 0 to 1 in steps of 0.1; it set E→I and I→E initializer means to <NativeMath markup={formulae[2]} /> and <NativeMath markup={formulae[3]} />, respectively, with standard deviations one tenth of those means and normalization by source population size. These lower-clamped normal weights replaced the zero recurrent matrices; learned input and readout weights stayed fixed, and E→E and I→I coupling stayed zero. The same network seed was reused across strengths; no optimization followed the intervention.

3. **Evaluate responses.** Each strength used the same <LiveValue report="exp038" expression={"eval_n"} /> images from the official <LiveValue report="exp038" expression={"eval_pool"} />-image test partition, with 200 ms presentations and 0.1 ms steps. Uniform independent Poisson inputs covered 26 rates between 0 and 100 Hz, with 32 trials per rate; a separate trained-loop probe used one test image at ten maximum pixel rates from 0 to approximately 23.08 Hz.
