## Abstract

We asked which input rates preserve enough information in filtered MNIST pixel events for nonlinear decoding. We trained {seedCount} decoders on finite-window, nonspiking membrane features and evaluated held-out digits. Mean accuracy increased from {pctDRowsFirstAccuracy} at {dRowsFirstRateHz} Hz to {pctDRowsLastAccuracy} at {dRowsLastRateHz} Hz. The tested range calibrates this representation and decoder; it does not establish PING-network accuracy or predict performance between tested rates.

## Methods

1. **Retained computation.** We reused a completed calibration containing three trained decoders, their validation histories and their held-out correctness records. We did not rerun feature simulation or decoder training for this article.

2. **MNIST partitions.** Of the {availableTrainingImages} official training images, the first {trainingImages} trained the decoders and the next {validationImages} selected checkpoints; the remaining {unusedTrainingImages} were unused. Evaluation used the first {testImages} images from the separate official test partition, with no overlap.

3. **Generate input events.** Each normalized pixel intensity $x_{i} \in [ 0 , 1 ]$ generated an independent binary event $s_{i [ k ]}$ at integration timestep $\Delta t_{\text{sim}} =$ {pDtMs} ms:

   $$
   p_{\text{event} , i} = \frac{r_{\text{input,max}} x_{i} \Delta t_{\text{sim}}}{1000} , \quad s_{i [ k ]} \sim \text{Bernoulli} ( p_{\text{event} , i} ) .
   \tag{1}
   $$

   Here $i$ indexes pixels, $k$ is the simulation-step index, $p_{\text{event} , i}$ is event probability, and $r_{\text{input,max}}$ is maximum-pixel encoding rate in spikes/s; 1000 converts milliseconds to seconds.

4. **Filter synaptic conductance.** Excitatory conductance $g_{i [ k ]}$, in μS, decayed each step by $\exp(-\Delta t_{\text{sim}}/\tau_{\text{AMPA}})$ before an event added $w_{\text{event}}$. The AMPA time constant was $\tau_{\text{AMPA}} = 2$ ms and event strength was $w_{\text{event}} =$ {pProbeUs} μS.

5. **Integrate membrane voltage.** During simulation step $k$, the updated conductance $g_{i [ k ]}$ was held fixed while each non-spiking membrane voltage $V_{m , i} ( t )$ obeyed

   $$
   C_{m} \frac{d V_{m , i}}{d t} = g_{L} ( E_{L} - V_{m , i} ) + g_{i [ k ]} ( E_{e} - V_{m , i} ) .
   \tag{2}
   $$

   Capacitance was $C_{m} = 1$ nF, leak conductance $g_{L} = 0.05$ μS, leak reversal $E_{L} = - 65$ mV and excitatory reversal $E_{e} = 0$ mV. Starting at zero conductance and $E_{L}$, voltage advanced by the exact exponential solution for that step. Simulation and decoder arithmetic used single precision.

6. **Form pixel features.** The feature $z_{\text{feature} , i}$, in mV, averaged post-update voltages above rest:

   $$
   z_{\text{feature} , i} = \frac{1}{N_{t}} \sum_{k = 1}^{N_{t}} ( V_{m , i} ( k \Delta t_{\text{sim}} ) - E_{L} ) \approx \frac{1}{T_{\text{present}}} \int_{0}^{T_{\text{present}}} ( V_{m , i} ( t ) - E_{L} ) \, \mathrm{d} t .
   \tag{3}
   $$

   Here $T_{\text{present}} =$ {pPresentationMs} ms, $N_{t} = \frac{T_{\text{present}}}{\Delta t_{\text{sim}}}$ is the timestep count, and physical time at step $k$ is $t_{k} = k \Delta t_{\text{sim}}$. Fresh encoding draws retained finite-window shot-noise effects without a stationary Gaussian approximation\[[1](#ref-1)\].

7. **Train mixed-rate decoders.** At every epoch, we sampled the input rate for each training and validation presentation uniformly from {inputRates} Hz and generated a fresh encoding draw. Each 784–1024–10 ReLU decoder was trained for {epochs} epochs using cross-entropy, Adam with learning rate 0.001, no weight decay and batch size 1.

8. **Independent training replicates.** Stochastic-stream identifiers {seeds} defined independent model initializations, rate assignments and encoding draws.

9. **Select checkpoints.** At each of the {epochs} eligible epochs, validation accuracy was the fraction correct across {validationImages} validation presentations. The earliest epoch attaining the maximum validation accuracy supplied the selected checkpoint for each training replicate.

10. **Evaluate shared test features.** Every held-out image was simulated once at each tested rate, and all selected decoders received the same feature vector for that image and rate; the feed-forward decoder had no state across presentations. The predicted class $\hat{y}$ was the class $c$ with the largest output logit $z_{c}$, and accuracy was measured per training replicate and rate.

11. **Aggregate held-out accuracy.** For each rate and training replicate, we averaged correctness across {testImages} held-out images. We then recorded the mean, minimum and maximum accuracy across the {seedCount} training replicates at each rate.

12. **Select the tested interval.** The practical floor was the lowest tested rate where every decoder reached {pctPUsefulAccuracy} accuracy, and the ceiling was the highest tested rate. No interpolation was used; an empty qualifying set was reported as right-censored.

13. **Present retained evidence.** We redrew the validation trajectories and rate-accuracy summary from recorded measurements, using the aggregation defined above without interpolation. We reused the original finite-window feature illustration unchanged rather than implying a new simulation.
