## Used-Transmission Measurement

1. Use the exact seed-{data?.used_window ? data.used_window.seed : 'unavailable'} trial in Figures 2–3. Detect whole A/B excitatory volleys with the same 1-ms-smoothed peak detector and trough boundaries used for C decoding. Test every observed packet whose complete one- and two-cycle C outcome lies within a settled measurement window. No packet is selected using C’s dominant pattern.
2. Replay the saved A/B spikes only on their existing E→C E projections, preserving native weights, delays, original sender activity and all other drive. Every unperturbed prefix, control continuation and final tail must reproduce the original spike arrays exactly. For each deletion, restore the identical native state and omit only one observed sender packet; verify unchanged sender spikes and unchanged C activity before the omitted input could arrive.
3. Fit the existing nonnegative background and A/B spatial templates to integrated C E spike counts over one complete baseline C cycle and then over that cycle plus the next. Keep fixed baseline boundaries for both continuations. Subtract deleted-packet amplitudes from control amplitudes; divide two-cycle differences by two. For each horizon, retain both the removed sender’s own-pattern loss and its own-minus-competing-pattern loss. The persistent contribution is the minimum of these four signed differences. It is positive only if the sender supports its own spatial representation and its relative advantage at both horizons. Negative effects remain negative. Within-cycle timing shifts alone leave integrated counts unchanged; the second horizon checks persistence beyond the first cycle.
4. Assign each packet the sender-minus-C phase plotted at the associated receiver peak, retaining native delays during execution. Divide wrapped phase into {data?.used_window ? data.used_window.settings.phase_bins : 'unavailable'} equal bins. Shade only bins with at least {data?.used_window ? data.used_window.settings.minimum_events : 'unavailable'} actual packets and a median persistent contribution at least half the positive supported peak. Bin boundaries represent finite resolution, not precise physiological thresholds. This defines strong used transmission; it does not exclude weaker contributions elsewhere.
5. Retain every packet-level outcome, phase occupancy and signed effect. Check bin counts 12/16/24, quarter/half/three-quarter peak cutoffs, separate sender/cue summaries, leave-one-receiver-state-out stability and packet-strength-normalised effects. These are descriptive sensitivity checks on correlated states from one seed, not independent validation. Sparse phases are under-sampled, not proven dynamically inaccessible. Packet deletion measures causal contribution in the operating circuit, including recurrent competition; it is not a sufficiency test for arbitrary input pulses.
