## Abstract

We tested whether a small fully connected spiking network could classify low-resolution handwritten digits using brightness-dependent input spikes. A leaky integrate-and-fire hidden layer and spiking output layer learned through surrogate gradients, reducing training and validation loss. A checkpoint selected by validation loss also classified held-out images accurately. This single training replicate provides a compact supervised baseline; it does not establish robustness across seeds, writers, or input encoding draws.

## Methods

1. **Partition handwritten digits.** We used all 1,797 images from scikit-learn's bundled digits dataset [1], a separate dataset from MNIST. Each image contains 64 intensities on an 8 × 8 grid, with integer values from zero to 16 and a label from zero to nine. A stratified split with seed 42 reserved 360 test images. A second stratified split with seed 43 divided the remaining images into 1,077 training and 360 validation images. We normalized intensities by dividing by 16. Splits were disjoint by image, without writer-group constraints.
2. **Encode brightness as spikes.** Each image was presented for 50 ms using 50 steps of 1 ms. At each step, every pixel independently generated a Bernoulli event with probability equal to its normalized intensity multiplied by 0.25. The maximum event rate was therefore 250 Hz. This is a discrete rate code; its relatively large maximum per-step probability should not be treated as a fine-grid Poisson approximation. Training used fresh events. Evaluation reset a split-specific random stream for every complete split, holding the encoding draws fixed across epochs. Seeds were 45 for training encoding, 52 for training evaluation, 53 for validation and 54 for test.
3. **Define the spiking classifier.** We used 64 inputs, 128 hidden LIF neurons and ten output LIF neurons, with two fully connected signed weight matrices. Both LIF layers had dimensionless decay 0.9 and threshold 1, with delayed subtractive reset; no refractory interval or explicit inter-neuron recurrence was added. Dense weights followed the default fan-in-scaled uniform initialization, with both biases initialized to 0.1. Hidden and output states reset at every image boundary. Class scores were output spike counts accumulated across the complete presentation, and prediction selected the largest count, choosing the lowest class index on ties. The decoder therefore knew the presentation boundaries.
4. **Optimize and select parameters.** With initialization seed 42, we trained both dense weight matrices and biases using cross-entropy on output spike counts, Adam at learning rate 0.001, zero weight decay, minibatches of 64 and 50 epochs. A separate stream with seed 44 shuffled the training images. Backpropagation through time used fast-sigmoid surrogate derivatives of slope 25 [2]; the global gradient norm was clipped at 1. We evaluated complete training and validation partitions at epoch zero and after every epoch, in batches of at most 256. Loss was averaged over images and accuracy was the fraction classified correctly. We selected the lowest validation cross-entropy among epochs zero through 50, choosing the earliest epoch on ties, and evaluated test images once with that checkpoint.
5. **Measure execution and learning.** We recorded every epoch's split loss and accuracy, checked finite training losses and gradients, and validated finite selected parameters and changed hidden/readout weights. The analysis verified disjoint exhaustive partitions, checkpoint selection and agreement between test accuracy and recorded predictions. One CPU execution and one training seed were used. Neither calibrated probabilities nor uncertainty across independently trained networks was measured.
