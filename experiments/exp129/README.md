# exp129 — Introduction to capacitors

Explore an ideal resistor–capacitor circuit and an illustrative Hodgkin–Huxley membrane
driven by an added excitatory synapse.

## Run

The demonstrations run interactively in the browser. From the repository root,
regenerate their network illustrations without simulation:

```sh
uv run python experiments/exp129/present.py
```

## Folder guide

1. `present.py` — regenerate network illustrations.
2. `report/` — report, appendix and supporting components.
3. `report/js/` — interactive browser demonstrations.
