## Abstract

Two SNNLab controllers, each containing one Elevate neuron, drive opposing
muscles on a rotary joint. Motor spikes activate muscles and inhibit the peer
controller; joint-angle feedback excites each neuron. Three ROS2 Humble nodes
run in Docker on separate CPUs with a 1 ms control period. A tip mass under
gravity makes flexion and extension asymmetric.

## Neuron Model

Elevate is a phenomenological conductance-based neuron with sodium, potassium,
calcium, slow potassium and leak currents:

$$
C\frac{dV}{dt}=I_0+g_e(E_e-V)+g_i(E_i-V)
+\sum_{k\in\{\mathrm{Na},\mathrm{K},\mathrm{Ca},\mathrm{KCa},L\}}g_k(E_k-V).
$$

$V$ is membrane voltage, $t$ time, $C$ capacitance and $I_0$ constant applied
current. Excitatory and inhibitory conductances $g_e,g_i$ have reversals
$E_e,E_i$; intrinsic conductance $g_k$ has reversal $E_k$. Units are mV, ms,
nF, µS and nA; no biological cell-area calibration is assumed.

For gate index $j\in\{m,h,n,c,q\}$,

$$
\tau_j\frac{dU_j}{dt}=V-U_j,\qquad
x_j=\sigma\!\left[a_j(U_j-b_j)\right],\qquad
\sigma(z)=\frac{1}{1+\exp(-z)}.
$$

$U_j$ is filtered voltage (mV), $\tau_j$ its timescale (ms), $x_j$ a
dimensionless gate, $a_j$ sigmoid slope (mV$^{-1}$), $b_j$ midpoint (mV),
and $z$ the dimensionless sigmoid argument. In order $m,h,n,c,q$, slopes are
$(0.2,-0.1,0.1,0.2,0.1)$ and midpoints $(-25,-40,-15,-45,-30)$ mV.
These gates control sodium activation/inactivation, potassium activation,
calcium activation and slow potassium activation:

$$
g_{\mathrm{Na}}=\bar g_{\mathrm{Na}}x_mx_h,\quad
g_{\mathrm{K}}=\bar g_{\mathrm{K}}x_n,\quad
g_{\mathrm{Ca}}=\bar g_{\mathrm{Ca}}x_c,\quad
g_{\mathrm{KCa}}=\bar g_{\mathrm{KCa}}x_q,\quad g_L=\bar g_L.
$$

$\bar g_k$ is maximum conductance. Both potassium currents use the potassium
reversal. KCa depends on filtered voltage; there is no calcium-concentration state.

## Joint Dynamics Model

Two muscles drive a damped rotary joint with a restoring spring and tip mass.
The arm contributes inertia but no gravitational mass. Zero points downward;
positive angles point right. Pendulum torque balance gives

$$
(J_0+mL^2)\ddot{\theta}+b\dot{\theta}+k(\theta-\theta_r)+mgL\sin\theta
=\tau_{\max}(a_f-a_e).
$$

$\theta$ is angle (rad); dots denote derivatives in seconds. $J_0$ is base
inertia (kg m$^2$), $m$ tip mass (kg), $L$ arm length (m), $g$ gravity
(m/s$^2$), and $\theta_r$ spring rest angle (rad). Total inertia is $J_0+mL^2$;
$b$ is damping (N m s/rad), $k$ stiffness (N m/rad), $a_f,a_e\in[0,1]$
flexor/extensor activation, and $\tau_{\max}$ maximum muscle torque (N m).

At mechanical step $n$, muscle $i\in\{f,e\}$ updates as

$$
a_{i,n+1}=\min\!\left(1,
a_{i,n}\exp[-\Delta t/\tau_a]+q\,s_{i,n}\right).
$$

$\Delta t$ is timestep and $\tau_a$ activation decay time (seconds); $q$ is a
dimensionless increment. $s_{i,n}$ is accepted motor spike count divided by neuron
count. Spikes accumulated between callbacks enter the first mechanical step;
subsequent steps receive zero. Activation decays before spikes are added and is
capped at one. Spike increments are not multiplied by $\Delta t$.

Updated activations set torque. Semi-implicit Euler updates velocity from the
old angle and velocity, then angle from the new velocity. Initial angle is
$\theta_r=\pi/2$ (90°); velocity and activations start at zero. Stops at
$\theta_r\pm1$ rad clamp angle and zero velocity. Spring rest and sensory centre
equal $\theta_r$.

Flexor torque raises the mass against gravity; extensor torque lowers it.
Initial gravitational torque is $-0.003924$ N m and total inertia is
$0.00508$ kg m$^2$. Gravity makes the two muscles' mechanical effects asymmetric.

Before each mechanical update, sensory spikes excite the flexor when
$\theta<\theta_r-\theta_s$ and extensor when $\theta>\theta_r+\theta_s$.
$\theta_s$ is the sensory threshold (rad). Each channel enforces a minimum
interspike interval and fires repeatedly beyond threshold.

## Architecture Pseudocode

Three ROS2 nodes implement flexor, extensor and joint dynamics. The controllers
use SNNLab; the joint uses Python mechanics. Each update advances 1 ms of model time.

Logical transport exchanges indexed spike windows, including empty windows.
Each node waits for both inputs from the preceding step, fixing the coupling
delay at one step. Waiting contributes to wall-clock lag and deadline misses;
there is no hard-real-time guarantee.

### Controller network

`snnlab.lang` pseudocode; connection parameters are omitted.

```python
from snnlab import lang
from experiments.exp152.custom.elevate import DEFINITION, register

register()

def controller(name):
    net = lang.Network(name, dt=1 * lang.ms)

    motor = net.population(
        "motor", size=1,
        neuron=lang.CustomNeuron(DEFINITION, ...),
    )
    tonic = net.input("tonic", signal_type="continuous", ...)
    sensory = net.input("sensory", signal_type="spikes", ...)
    peer = net.input("peer", signal_type="spikes", ...)

    net.connect(tonic, motor.excitatory, synapse=lang.CustomSynapse(...), ...)
    net.connect(sensory, motor.excitatory, synapse=lang.AMPA(...), ...)
    net.connect(peer, motor.inhibitory, synapse=lang.GABA(...), ...)

    net.output("motor_spikes", motor.spikes)
    return lang.compile(net)

flexor = controller("flexor")
extensor = controller("extensor")
```

### Flexor ROS2 Node

```python
def tick():
    # ROS2: receive spikes.
    sensory = take_spikes("sensory/flexor")
    peer = take_spikes("motor/extensor")

    # SNNLab: advance the Elevate neuron.
    spikes = flexor.advance(
        startup_excitation=local_startup_pulse(),
        excitation=sensory,
        inhibition=peer,
        duration_ms=1,
    )

    # ROS2: send motor spikes to joint dynamics and extensor.
    publish("motor/flexor", spikes)
```

### Joint Dynamics ROS2 Node

```python
def tick():
    # ROS2: receive motor spikes.
    motor = [
        take_spikes("motor/flexor"),
        take_spikes("motor/extensor"),
    ]

    for step in substeps(duration_ms=1):
        # Custom Python: encode joint angle as sensory spikes.
        sensory = joint.encode()

        # ROS2: send sensory spikes to the controllers.
        publish("sensory/flexor", sensory[0])
        publish("sensory/extensor", sensory[1])

        # Custom Python: update muscle activation and mechanics.
        joint.advance(motor, dt=0.001)
        motor = [0, 0]  # Apply received spikes once.
```

## Timings

A **callback** advances one node and publishes its outputs. Its **deadline** is
1 ms after the scheduled start. Late starts and long callbacks can cause misses.
