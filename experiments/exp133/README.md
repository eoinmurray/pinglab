# exp133 — Lowet (2015): Coupled Rhythms

Standalone conductance-LIF experiment. The scientific design is an 11 × 13 grid
of signed input imbalance and jointly varied reciprocal E→E/E→I coupling.
The current map and sender–receiver protocol both use 1,024 input channels
per circuit. The sender–receiver copies the selected saved map matrices.

## Commands

```sh
uv run python experiments/exp133/compute.py --parameter-source exp133-r025-compute
uv run python experiments/exp133/analyse.py --source <compute-run-id>
uv run python experiments/exp133/present.py --source <analyse-run-id>
```

Each stage prints one new immutable v4 ID. Pass the exact completed upstream
identity explicitly. There is no latest-input fallback or implicit dispatch.
The Astro report is discovered automatically from `report/report.mdx`.

## Scientific design

1. Mean input is fixed at 25 Hz per channel. Signed A-minus-B input imbalance
   spans −10 to +10 Hz in 2 Hz increments, giving individual rates 20–30 Hz.
   Native request scales multiply both input projection strengths by 9.2,
   matching the current sender–receiver input gain. The horizontal map axis is the *measured
   uncoupled E-volley frequency difference*, not the prescribed input imbalance.
2. Equal reciprocal E→E/E→I nominal total strengths span 0–0.12 μS in 0.01 μS
   increments. Each cross-network target receives exactly eight afferents with
   2 ms delay. All 143 points share network seed 85 and input seeds 8501/8502.
3. One 500 ms uncoupled batched prefix is copied into each coupling condition,
   followed by 4.5 s of paired input. Analysis excludes the next 300 ms. The
   eleven batch slots are conditions, not independent replicates.
4. Native `StepGain` activates cross-network transmission at 500 ms. A single
   retained portable bundle with base cross-coupling 0.12 μS supplies all
   requests. Native `projection_scales` sets each condition's parameter values;
   start/end snapshots retain the actual matrices. Local weights and sparse
   connectivity remain the same throughout.
5. Finite-time locking requires valid gamma rhythms, absolute phase drift
   below 0.25 cycles/s, PLV above 0.95, and total relative-phase
   span below one cycle. Invalid rhythms are masked separately. No analytical
   boundary or seed robustness is inferred from the sampled binary mask.
