## Appendix A — Recording and clock conventions

### A1 — Output clock

Both architectures use a discrete COBA-LIF output layer on the same graph clock
as their hidden neurons, or a continuous COBA-LIF output population. Native
clock values below are verified against the executed SNNLab snapshots; CT
means continuous time. Output spike counts remain the class score throughout.

### A2 — Input alignment and recording

The sweep uses 0.1, 0.05, 0.025 and 0.0125 ms timesteps. SNNLab
generates one encoding at a 100 Hz maximum pixel rate on a fixed 0.2 ms grid,
so every arrival lies exactly on every numerical clock. We compare the resolved
input coordinates against the saved schedule and retain their checksum and zero
timing error for every execution. Input spikes are neither regenerated nor
rounded when changing the timestep. A separate replay of the saved 25 Hz
encoding validates the original trained model and does not enter these plots.

Sweep and continuous states share a 0.1 ms recording clock. Native-clock
inference retains its 0.2 ms clock and the same 100 Hz encoding. Its error
statistics select the
continuous reference's exact existing 0.2 ms sample times, without interpolation.
All spike timestamps retain their original resolution.

### A3 — Arrival clocks

SNNLab labels conductance by the start of a slot and voltage/spikes by its end.
A recurrent projection with declared delay $d$ therefore has end-clock lag
$d-h$, where $h$ is the numerical timestep. Matched E–I edges declare
$0.2\,\mathrm{ms}+h$. The matched hidden-to-output edge uses one slot, giving
zero additional physical lag. The native 100 Hz case preserves the trained
graph's
same-slot readout and one-slot E–I edges; its E–I end-clock lag is zero and its
readout starts within the same integration slot as the hidden spike. These
native timings are retained separately from the physical-delay comparison.
The original 25 Hz reproduction controls remain separate validation evidence.
Refractory timing retains the source's native
`following_steps` convention in discrete executions.

The continuous reference implements the physical-delay convention. Its
numerical refinement establishes local solver stability for this input; it
does not establish convergence of the discrete recurrent trajectories.

### A4 — Retained voltage samples

For each neuron, the voltage-error calculation excludes inclusive ±2 ms
windows around either train's spikes. Entries below are the median retained
sample fraction across each population. Error medians describe these retained
samples; they are not full-waveform errors.
