The initial signal test used the same mean drives and added the independent modulations
below. Each sensory/noise sequence was paired across cue orders. The following
settings were fixed before test scores were inspected.

| Signal-test setting | Value |
| --- | --- |
| Signal generation | Independent Gaussian sequences on 10 ms bins, smoothed with a 50 ms Gaussian, tanh transformed, centred and bounded within ±1 |
| Signal modulation | Up to ±1.5 Hz/channel around each sender’s 33 Hz/channel drive; present for all 4 seconds |
| Training / test sequences | 3 / 3 independent signal and Poisson-noise sequences; each with S1→S2 and S2→S1 cue orders |
| New input seeds | Reference seeds plus 100000, 101000, 102000 for training; plus 200000, 201000, 202000 for testing |
| Signal seeds, S1 / S2 | 236000 / 236001, 236010 / 236011, 236020 / 236021 for training; 336000 / 336001, 336010 / 336011, 336020 / 336021 for testing |
| Readout features | Per-cell mean E/I rates in trailing 20 ms windows at lags 0, 10, 20, 30 and 40 ms; input readout uses input spikes only |
| Predicted signal | Signal 20 ms before the latest receiver observation; sampled every 10 ms |
| Decoder | Ridge regression with penalty 10 against summed squared training error; training-only centring and feature scaling; separate fixed readouts for each condition and signal |
| Scored times | 1160–1990 and 2160–2990 ms, every 10 ms; both cue orders combined within each test sequence |
| Timing control | Native replay of independently permuted sender E spike times within 50 ms blocks; exact per-cell block counts retained |
| Receiver controls | Same sensory/cue inputs and starting state, with zero coupling or scrambled sender timing |
| Aggregation | Mean of three independent test-sequence scores; cue orders are paired observations, not independent replicates |

Receiver cue benefit was measured within each signal, avoiding a preference
caused merely by one signal being easier to decode. A timing-based interpretation
also required both signals’ cued reconstruction and cue benefit to exceed the
scrambled condition. All comparisons were descriptive; no significance claim
was made from three test sequences.

### Signal-routing search

| Setting | Coarse range | Selected fine value |
| --- | --- | --- |
| Sensory modulation bound, Hz/channel | ±1.5 to ±15 | ±12.211 |
| Gaussian smoothing standard deviation, ms | 25–250 | 82.153 |
| Sender-to-R total per target/pathway, μS | 0.015–0.135 | 0.079802 |
| Cue-to-sender total per excitatory target, μS | 0.015–0.18 | 0.115533 |
| Sender / receiver mean drive, Hz/channel | Fixed | 33 / 35 |
| Trial / cue-segment duration, ms | Fixed | 4,000 / 1,000 |
| Search candidates | Original setting plus 16 coarse points | Coarse centre plus 16 fine points |
| Fine bounds | Coarse centre ±35%, clipped to coarse ranges | Same four axes |
| Search training / validation pairs | 1 / 1, each in both cue orders | Same draws reused for refinement |
| Confirmation training / test pairs | Never used during search | 3 / 3 fresh pairs, each in both cue orders |
| Decoder | Fixed across the new search and confirmation | 50 ms windows at lags 0, 25, 50 ms; 50 ms target delay; 10 ms sampling; ridge penalty 10 |
| Scored cue times, ms | Fixed | 1,200–1,990 and 2,200–2,990 |

The coarse points were a seeded Latin-hypercube sample, which spreads trials
across each range. The fine sample used the same method within the smaller
bounds. After readability and positive-score checks, selection maximised the
smaller cue benefit. Remaining ties used the smaller cued receiver score,
then the smaller sender score, then earlier candidate order. If no candidate
met the readability threshold, the fallback would maximise the weaker sender
score; it would not count as successful attention.

Connection masks and local weights were preserved. Coupling and cue weights
changed only between settings; every weight remained constant during each
trial. Figure 3 uses newly simulated signals and fresh tests; Figures 1–2
remain the earlier synchrony references. The scrambling control preserved exact
per-neuron counts in every 50 ms block and retained mean sender reconstruction
scores of 0.460/0.456. It reduced sender gamma power fractions from about 0.46
to 0.26, but also changed coincidences and sender-local dynamics, so it does
not isolate inter-network phase alone. Test scores remain descriptive.
