Spike-Count Classification in a Continuous Stream#

Abstract#

This experiment asked whether networks trained on separate MNIST digits could classify digits presented continuously. Recurrent state was preserved between digits, while the output decision was reset at each boundary.

Classification improved with longer, stronger inputs, whereas weak inputs often produced no output spikes.

Results#

Five-digit capability stream#

One variable-rate-trained PING network classified a five-digit MNIST stream using output-LIF spike counts. Hidden neuronal state continued between presentations, while output state and counts reset at each known boundary (Fig. 1).

If the classifier tolerated both carried state and changing input rate, at least some complete streams should remain correctly classified.

Before inference, we fixed candidate order and selected the first stream classified 5/5 correctly. The first candidate qualified, so no failed candidate was skipped to obtain this image.

Duration-rate classification accuracy#

Three independently trained PING networks classified continuous MNIST streams while presentation duration and maximum-pixel input rate varied. Hidden state persisted between digits, but each output decision reset at the boundary (Fig. 2).

Longer and stronger presentations should provide more output evidence, reducing silent decisions and improving classification.

Classification improved with longer and stronger inputs. Brief, weak presentations frequently produced no output spikes, while performance remained strong across the denser input conditions.

Single-trial spike-count decision#

One correctly classified digit from the continuous stream was examined to show how excitatory and inhibitory spiking became an output spike-count decision (Fig. 3).

A correct decision should end with the true class holding the largest cumulative output spike count.

Class-specific output spikes accumulated until class 4 held the largest count at the presentation boundary.

Output-count transition#

A short interval from the same digit-4 presentation was enlarged to explain an abrupt change in the displayed class shares (Fig. 4).

From the readout definition, counts should remain flat between output spikes and step upward only when the corresponding class neuron spikes.

The displayed counts formed non-decreasing integer staircases. Softmax normalization then changed every class share at each count increment.

Three-of-five counterexample#

The same network, durations, rates and deterministic candidate order used for the successful showcase were searched for a stream containing exactly three correct decisions (Fig. 5).

If the showcase represented capability rather than perfect reliability, comparable streams should also contain classification errors.

The first stream scoring exactly 3/5 was candidate 17, after 17 candidates were evaluated. Digits 9 and 2 were misclassified as 4 and 9.

Mixed-duration failure modes#

A five-digit stream varied both presentation duration and input rate to expose the classifier to easy and difficult conditions within one continuous trajectory (Fig. 6).

Brief or weak presentations should be most vulnerable because they provide less time or input for output evidence to accumulate.

3 of 5 decisions were correct. The 200 ms, 0.5 Hz presentation was silent, while the 100 ms, 2 Hz presentation failed despite producing output spikes.

Methods#

  1. Classifiers. We reused three frozen PING networks, seeds 42–44, from exp022 — Training Runs. We did not retrain them. Their variable-rate training and our evaluation used eleven maximum-pixel input rates spanning 0.5–25 Hz, motivated by the filtered-input calibration in exp080 — Decoder Accuracy Improves with Input Rate.

  2. Architecture. Each network contained 1,024 excitatory neurons, 256 inhibitory neurons and ten output-LIF units. A learned projection carried excitatory spikes to the output units.

  3. Training provenance. Training used 6,300 optimization and 700 validation MNIST images for 50 epochs, sampling eleven maximum-pixel rates from 0.5 to 25 Hz.

  4. Checkpoint selection. Minimum validation cross-entropy, averaged over three encoder draws, selected each checkpoint; validation accuracy broke ties. Neither final-epoch weights nor the official test partition selected the models.

  5. Test data. Evaluation sampled the official 10,000-image MNIST test partition. Each duration–rate–seed condition contained 40 independent five-digit streams, giving 200 digit decisions.

  6. Batching. Five streams ran per batch with separate neuronal states. The corrected execution concatenated streams along the batch axis without changing the experimental recipe.

  7. Input encoding. Pixels generated independent Bernoulli spikes at 0.1 ms resolution, scaled by the condition’s maximum-pixel input rate.

  8. State handling. Hidden neuronal state persisted between digits within a stream. Output-LIF state and spike counts reset at every known boundary.

  9. Condition grid. Presentations lasted 25, 50, 100 or 200 ms at each of the eleven training rates. Presentation and readout windows were always equal.

  10. Count class spikes. During each presentation, the score for class 𝑐 was its total output-spike count:

    𝑧𝑐=∑𝑘∈presentation𝑠𝑐[𝑘].
    (1)

    Here 𝑘 is a simulation timestep and 𝑠𝑐[𝑘] is 1 when output unit 𝑐 spikes and 0 otherwise.

  11. Predict the digit. Prediction selected the largest entry in the ten-class score vector 𝑧: 𝑦̂=argmax(𝑧). Ties selected the lowest class index, including class 0 when every output count was zero.

  12. Illustrative streams. Seed-42 figures reused one five-digit matched stream and one fixed changing-duration/rate stream. The nominal-regime figures used 200 ms digits at 5, 7.5, 10, 15 and 25 Hz.

  13. Candidate selection. Before inference, we fixed ascending candidate order and derived deterministic digit and encoding seeds from each index. We selected the first 5/5 stream as the capability showcase and the first 3/5 stream as its counterexample; the search stopped after 17 candidates.

  1. Explanatory close-up. The single-digit figure used the first correct matched presentation. Its 91.5–94.5 ms enlargement was selected post hoc around the displayed transition.

  2. Display count shares. Figures transformed the score vector with

    𝑞=softmax(𝑧).
    (2)

    Here 𝑞 is the displayed vector of class shares. It is not a calibrated posterior probability.

  3. Measure accuracy. We calculated accuracy separately for each duration–rate–network condition as the proportion of correct decisions. Each condition contained 200 decisions.

  4. Retained measurements. We recorded the original per-seed aggregates of accuracy, class spike totals, output spikes per presentation, silence and E/I rates. Individual grid decisions were not archived; E/I rates used all 1,024/256 neurons across the complete presentation.

  5. Summaries and limits. Seed means and SEM summarize three training replicates, not 600 independent network replicates. No additional stream-bank repeats, adjusted comparisons, population-level intervals, causal gamma manipulation, fixed-rate-training control or separation of viewing from integration time support broader claims.

  1. Render figures. The presentation stage rendered the article figures from saved analysis and its explicitly linked compute recordings. It did not rerun inference, reselect an illustration or recompute condition statistics.
