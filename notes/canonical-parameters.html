Notes

These are canonical parameters for decent conductance-based (COBA) and pyramidal–interneuron gamma (PING) behaviour, following the shared TR01/TR02 recipe in exp022. E and I denote excitatory and inhibitory neurons; paired values below are E / I. LIF means leaky integrate-and-fire.

ParameterCanonical value
Network and input
Input / hidden E / hidden I / output neurons784 / 1,024 / 256 / 10
Input encodingIndependent Poisson pixel channels; 25 Hz at maximum pixel brightness
Presentation / timestep200 / 0.1 ms; 2,000 updates per presentation
State between presentationsReset
E→I→E loop strengthCOBA: 0; PING: 1
E→E / I→I recurrenceAbsent
Recurrent connection delayOne timestep (0.1 ms)
Neuron and synapse dynamics
Hidden neuronsConductance-based LIF
Membrane capacitance, E / I1.0 / 0.5 nF
Leak conductance, E / I0.05 / 0.10 µS
Membrane time constant, E / I20 / 5 ms (capacitance divided by leak conductance)
Resting / reset / threshold voltage−65 / −65 / −50 mV
Refractory hold, E / I1.2 / 0.6 ms
AMPA / GABA synaptic decay2 / 6 ms
ReadoutTen spiking LIF neurons; temporal mean of pre-reset voltage supplies class logits
Readout time constant / soft-reset threshold2 ms / 1 (dimensionless threshold)
Weights and learning
Input-weight initializationNormal parent mean 0.9, standard deviation 0.09; clamp negatives to zero, randomly zero 95%, then divide by (0.05 × 784)
PING E→I initializationNormal mean 1, standard deviation 0.1; clamp negatives to zero and divide by 1,024
PING I→E initializationNormal mean 2, standard deviation 0.2; clamp negatives to zero and divide by 256

TR01 and TR02 training
DatasetMNIST; official test partition excluded from optimization and checkpoint selection
