Abstract

Two single-neuron Elevate controllers drive opposing muscles on a rotary joint with a 2 g tip mass under gravity. Motor spikes activate muscles and inhibit the peer; angle feedback excites each controller. Three ROS2 Humble nodes exchange 1 ms spike windows in Docker on separate CPUs.

Results

Control Approach

The parameters were selected empirically by varying background excitation, sensory feedback strength and muscle response per spike. They remain fixed throughout the displayed recording.

Architecture Pseudocode

1. Overall

ROS2 Humble runs flexor, extensor and plant as separate processes on separate CPUs. All three receive the same resolved recipe configuration. Each controller owns an independent SNNLab stream containing one Elevate neuron; the plant integrates joint mechanics without a neural network. These Python-like blocks omit boilerplate. ROS2 scheduling and message helpers are schematic; prepare_stream and stream.advance denote SNNLab’s streaming interface.

from snnlab.sim import prepare_stream
from torch import float64

cfg = recorded_configuration
dt = cfg["dt_ms"] * ms
nodes = launch_ros2_processes("flexor", "extensor", "plant")
wait_for_ros2_discovery_and_controller_warmup(nodes)
arm_shared_start(nodes, future_ros_time())


def prepare_controller():
    bundle = author_network(cfg)
    stream = prepare_stream(
        bundle,
        window_steps=1,
        batch_size=1,
        device="cpu",
        dtype=float64,
        performance=recorded_performance,
    )
    warm_up_then_reset(stream)
    return stream


def windows(node):
    for n in range(total_windows):
        release = node.monotonic_origin + n * dt
        spin_ros2_until(node, release)
        frames = wait_for_ros2_frames(node, index=n - 1)
        enforce_lag_limit(release)
        with measure_callback(node, deadline=release + dt):
            yield n, frames
            publish_ros2_frame(node, n, node.output_events)

Each node consumes both other nodes’ complete preceding windows from /frames/flexor, /frames/extensor or /frames/plant. The initial inputs are empty; every completed window is published, including silence. Late nodes catch up without dropping windows or shifting deadlines. Callback timing includes model execution, spike publication and diagnostic buffering, but excludes input waiting. Buffered diagnostics are exported after control finishes.

2. Flexor node

The flexor receives excitatory sensory spikes from the plant and inhibitory motor spikes from the extensor. Its local excitation is 0.5 µS for the first 20 ms, then 0.04 µS. SNNLab retains membrane and synaptic state between steps.

node = create_ros2_node("flexor")
stream = prepare_controller()

for n, frames in windows(node):
    drive = cfg["flexor_initial_us"] if n * dt < 20 * ms else cfg["tonic_us"]
    inputs = snnlab_inputs(
        tonic=drive,
        sensory=count_sensory_spikes(frames["plant"], channel="flexor"),
        peer=count_spikes(frames["extensor"]),
    )
    result = stream.advance(inputs)
    node.output_events = motor_spike_events(result)
    publish_ros2_spikes("/motor/flexor", node.output_events)
    buffer_voltage_and_spikes(node, result)

3. Extensor node

The extensor receives excitatory sensory spikes from the plant and inhibitory motor spikes from the flexor. Its SNNLab stream is separate from the flexor’s. Local excitation starts at 0 µS for 20 ms, then switches to the same 0.04 µS tonic drive.

node = create_ros2_node("extensor")
stream = prepare_controller()

for n, frames in windows(node):
    drive = cfg["extensor_initial_us"] if n * dt < 20 * ms else cfg["tonic_us"]
    inputs = snnlab_inputs(
        tonic=drive,
        sensory=count_sensory_spikes(frames["plant"], channel="extensor"),
        peer=count_spikes(frames["flexor"]),
    )
    result = stream.advance(inputs)
    node.output_events = motor_spike_events(result)
    publish_ros2_spikes("/motor/extensor", node.output_events)
    buffer_voltage_and_spikes(node, result)

4. Plant/Joint node

The plant receives both controllers’ motor windows. Before advancing mechanics, it encodes the current angle as sensory spikes; motor spikes then update muscle activation and joint motion. Sensory output returns through ROS2 and enters the controllers in the next logical window. This node does not execute SNNLab.

node = create_ros2_node("plant")
joint = Joint(cfg["joint"])

for n, frames in windows(node):
    sensory = joint.encode(n * dt / second)
    motor = [count_spikes(frames["flexor"]), count_spikes(frames["extensor"])]
    joint.advance(motor, dt / second)
    node.output_events = sensory_spike_events(sensory)
    publish_ros2_spikes("/sensory/flexor", sensory[0])
    publish_ros2_spikes("/sensory/extensor", sensory[1])
    buffer_angle_velocity_and_activation(node, joint)
