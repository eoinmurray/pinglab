Spatial Gaussian Selective Relay

A rate cue selects between competing spatial Gaussian patterns in an A/B → C spiking circuit.

Abstract

A uniform rate cue selects which Gaussian spatial pattern C represents, but brief competing responses remain. Dominant spatial patterns cluster around a preferred relative phase; this association does not establish a receptive-window boundary. Raising C’s background input improves the tuned example; a five-input-seed sweep reveals a trade-off between attention conditions.

Question and Circuit

Can a uniform cue select between two simultaneous Gaussian spatial inputs, and why does C sometimes flicker toward the unattended pattern?

Key Details

  1. Spatial input: A and B receive simultaneous Gaussian bumps in firing rate, centred at different positions on a circular spatial map.
  2. Input→A/B weights: Fixed sensory weights blend a Gaussian connectivity kernel favouring nearby spatial positions with the original connectivity, preserving each target’s total incoming strength. Weights are not learned.
  3. A/B→C weights: A→C and B→C use identical fixed Gaussian weight matrices, favouring nearby spatial positions with matched incoming strength. Weights are not learned.
  4. Cue: A spatially uniform spike input adds 3 Hz/channel to the attended sender, switching from A to B at 1,200 ms. Both sensory inputs remain present.
  5. Local competition: A, B and C contain excitatory and inhibitory neurons. Input reaching C recruits inhibition, which can suppress a later competing burst.

How the receptive phase was measured

  • Remove each of 150 naturally occurring A/B volleys separately from its input to C. Test every eligible packet in the settled windows, without selecting on dominance.
  • Compare each removal with an exact matched continuation from the same native state. Preserve all other inputs, weights and delays; controls reproduce the original spikes.
  • Fit C’s spatial pattern over one and two complete cycles. Measure the loss of the removed sender’s pattern and its advantage over the competing pattern. Use the smallest effect across both measures and horizons, normalising the two-cycle result per cycle.
  • Shade phase bins with at least 3 observed packets and a median effect at least half the positive supported peak. Bin width is 1/16 cycle; the Appendix gives the full method and sensitivity checks.
  • This identifies strong transmission phases used in this trial. Weaker effects outside the band remain possible; sparsely sampled phases are unmeasured, not proven inaccessible.

Sweep: Stimulus Contrast Cue

The contrast advantage is now the cue: A’s Gaussian bump is stronger before the switch, B’s afterwards. The unattended bump, uniform sensory baseline, widths and weights stay fixed; the separate uniform cue is off. Contrast ratio means Gaussian excess amplitude above baseline, not total firing-rate ratio.

Sweep: C Background Drive

Explanation

  • Low background may leave C too weakly excited. The attended sender’s timing advantage may not reliably produce a dominant spatial response.
  • More background could make the attended response more reliable. Bringing C closer to firing threshold could help an attended volley arriving during low inhibition trigger a response, recruit inhibition and suppress later distractor input. Background supplies excitability; the sender supplies the spatial pattern.
  • Too much background could also hurt. It could trigger C prematurely or admit distractor input, potentially explaining the trade-off between attention conditions.
  • This remains a mechanistic hypothesis. Background also changes C’s firing rate and rhythm. Comparing pre-arrival membrane voltage, inhibition and response delay across settings would help distinguish these explanations.

Sweep: Uniform Cue Drive

Used-Transmission Measurement

  1. Use the exact seed-186 trial in Figures 2–3. Detect whole A/B excitatory volleys with the same 1-ms-smoothed peak detector and trough boundaries used for C decoding. Test every observed packet whose complete one- and two-cycle C outcome lies within a settled measurement window. No packet is selected using C’s dominant pattern.
  2. Replay the saved A/B spikes only on their existing E→C E projections, preserving native weights, delays, original sender activity and all other drive. Every unperturbed prefix, control continuation and final tail must reproduce the original spike arrays exactly. For each deletion, restore the identical native state and omit only one observed sender packet; verify unchanged sender spikes and unchanged C activity before the omitted input could arrive.
  3. Fit the existing nonnegative background and A/B spatial templates to integrated C E spike counts over one complete baseline C cycle and then over that cycle plus the next. Keep fixed baseline boundaries for both continuations. Subtract deleted-packet amplitudes from control amplitudes; divide two-cycle differences by two. For each horizon, retain both the removed sender’s own-pattern loss and its own-minus-competing-pattern loss. The persistent contribution is the minimum of these four signed differences. It is positive only if the sender supports its own spatial representation and its relative advantage at both horizons. Negative effects remain negative. Within-cycle timing shifts alone leave integrated counts unchanged; the second horizon checks persistence beyond the first cycle.
  4. Assign each packet the sender-minus-C phase plotted at the associated receiver peak, retaining native delays during execution. Divide wrapped phase into 16 equal bins. Shade only bins with at least 3 actual packets and a median persistent contribution at least half the positive supported peak. Bin boundaries represent finite resolution, not precise physiological thresholds. This defines strong used transmission; it does not exclude weaker contributions elsewhere.
  5. Retain every packet-level outcome, phase occupancy and signed effect. Check bin counts 12/16/24, quarter/half/three-quarter peak cutoffs, separate sender/cue summaries, leave-one-receiver-state-out stability and packet-strength-normalised effects. These are descriptive sensitivity checks on correlated states from one seed, not independent validation. Sparse phases are under-sampled, not proven dynamically inaccessible. Packet deletion measures causal contribution in the operating circuit, including recurrent competition; it is not a sufficiency test for arbitrary input pulses.
