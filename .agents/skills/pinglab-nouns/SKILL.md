# Pinglab nouns

Use Pinglab's noun registry whenever the user names one of its types or asks to
convert material into, update, review, or continue one of them.

Before acting, read [`../../NOUNS.md`](../../NOUNS.md) completely. Treat that
file as the canonical, live definition of the vocabulary and its shared
contracts; do not duplicate or silently extend those definitions here.

Identify the requested target noun and follow its contract, including any
family-level rules that precede it. Preserve the distinction between prospective
plans and executed records, evidence and inference, and user decisions and model
proposals. Apply repository governance from `AGENTS.md`; this skill supplies
vocabulary and artifact behavior, not independent governance.

If the named noun is being used conversationally rather than as a request to
construct or transform an artifact, use its registry meaning without forcing a
full serialized output.
