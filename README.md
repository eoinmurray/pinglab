# Pinglab

Conductance-based spiking neural networks with excitatory/inhibitory populations
and PING (pyramidal–interneuron gamma) dynamics.

Site: [pinglab.eoinmurray.info](https://pinglab.eoinmurray.info).

Main documentation lives in [`md/notes/`](md/notes/). Start with the
[Repository Guide](md/notes/repository-guide.md) for setup, publishing and the
guide index. Coding agents must read [`AGENTS.md`](AGENTS.md).
